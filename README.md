# CHROMA — Liquid Colour Lab

> **Create a palette. Find a feeling.**

CHROMA is a single-page colour palette generator for exploring vibrant, harmonious colour combinations. Generate five-colour palettes, preserve favourites, and copy HEX values in a responsive interface with a living gradient background.

## ✨ Features

- **Harmonious palettes** — generate five colours using analogous, complementary, split-complementary, and spectrum-based schemes.
- **Keep colours you love** — lock individual cards while refreshing the rest of the palette.
- **One-click HEX copying** — click a colour card to copy its HEX value.
- **Search by HEX** — filter the current palette and see whether any colours match.
- **Automatic generation** — start or stop a timed stream of new palettes.
- **Living visual design** — the background responds to palette colours, with liquid gradients, glass-inspired panels, and glossy colour cards.
- **Responsive and motion-aware** — adapts to smaller screens and respects reduced-motion preferences.

## 🚀 Getting started

CHROMA has no build step, package installation, or external JavaScript dependencies.

1. Clone or download this repository.
2. Open the project HTML file in a modern browser.

If you want a conventional entry point, rename the HTML file to `index.html`. You can also serve the folder with any local static web server.

## 🧭 How to use

1. Select **Create a Palette** or **Reimagine** to generate a new combination.
2. Select the lock on a colour card to preserve that colour during future generations.
3. Click a colour card to copy its HEX code.
4. Enter a HEX value in the search field to filter the visible cards.
5. Select **Auto Generate** to cycle palettes automatically, then **Stop** to pause.
